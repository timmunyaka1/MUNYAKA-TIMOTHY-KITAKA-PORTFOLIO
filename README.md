# Timothy Munyaka: Portfolio

Portfolio of Timothy Munyaka, Systems and Network Administrator (Kenya).

- `index.html`: home page (hero, key numbers, projects, experience summary, contact)
- `experience.html`: full work experience
- `skills.html`: education, skills and tooling
- `helpdesk/`: interactive demo of the Matungulu ICT Support Desk (runs in the browser with sample data; admin login `demo` / `demo`)
- `previews/`: screenshots used in the project cards
- `timothy-hero.webp`: hero portrait

Plain HTML, CSS and JavaScript. There is no build step: open `index.html` in a browser, or serve the folder
(for example `python -m http.server`) and visit `http://localhost:8000`.
